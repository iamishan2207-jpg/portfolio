## About the Project
A responsive personal portfolio website that shows my profile, education, skills and projects. It is built with HTML, CSS and JavaScript only.

## Features
- Home section with name and introduction
- About Me section with personal and academic details
- Education section with academic qualifications
- Skills section (technical and non-technical)
- Projects section (Personal Portfolio, To-Do List Manager, Expense Tracker, Mail Mind, Kavyashala)
- Achievements section (science exhibition wins)
- Certifications section
- Contact section with a JavaScript-validated form (no backend)
- Navigation menu linking all sections, with smooth scrolling
- Responsive design for mobile, tablet and desktop
- Dark / light mode toggle

## JavaScript Interactions
1. Dark / light mode toggle
2. Mobile hamburger menu
3. Contact form validation (name, email and message checks)
4. Smooth scrolling (using CSS `scroll-behavior`)

## Technologies Used
- HTML5
- CSS3 (variables, flexbox, grid, media queries)
- JavaScript (basics)

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure and content |
| `style.css` | Styling, layout and responsive design |
| `script.js` | Dark mode, mobile menu and form validation |

## How to Run
1. Keep all three files in the same folder.
2. Double-click `index.html` to open it in any web browser.
